## 文档改了怎么同步

`docs/DESIGN.md` 是唯一源文件，改完重跑脚本即可生成另外两种格式：

```bash
python tools/build_design_html.py docs/DESIGN.md docs/Octopus-设计文档-v0.1.html
python tools/build_design_docx.py docs/DESIGN.md docs/Octopus-设计文档-v0.1.docx
```

`tools/diagnose_html_width.py` 是排版检查工具：它注入脚本让浏览器报告有没有元素超出视口宽度，
用来确认生成的 HTML 在小屏上不会横向溢出。

## 设想的功能

- **录入** —— 拍照 / 相册导入，手动框选切题
- **题目清理**（重点）—— OCR 出印刷体文字，编辑后重新排版成干净题目；图形/公式区域保留原图
- **错题库** —— 列表、多选、按学科/时间筛选
- **变式题** —— 选中一道题，AI 生成同知识点、同难度的新题
- **打印** —— 排版后导出 PDF 或调用系统打印

## 设计要点

三个已经想清楚的关键判断，详细理由见设计文档：

1. **不做图像修复去笔迹**，改用**文本重建**——把印刷体 OCR 出来重新排版，
   结果必然干净；含图形/公式的题保留原图区域
2. **不做全自动**——自动切题和去笔迹都不可能 100% 准，改成自动预切分 + 手动微调，
   避免家长反复返工
3. **照片不上传**——OCR、切题、擦除全在本地跑；只有"生成变式题"调 LLM，且只传题干文字
